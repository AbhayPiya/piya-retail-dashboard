# Piya Retail Analytics

Read-only Streamlit dashboard for the Piya Retail portfolio demonstration.

Deploy with main file `dashboard/app.py` and Python 3.12. Set `DASHBOARD_DSN` privately in Streamlit Secrets to the restricted hosted Gold connection. Credentials, datasets, checkout code, and worker services are not included.

The dashboard displays historical data and simulated orders; no real payments are processed.
